# customer-profiles

Per-customer configuration for Showcase applications will live here, for example which application a customer's devices run and with what settings. It belongs only in Showcase: customer configuration never goes into NoWayOS or Screen Compiler.

**Empty on purpose.** This repository holds no customer profiles, customer names or customer data until these questions are decided:

* what a profile contains and what format it takes;
* how a profile is reviewed, approved and built into a device image;
* which details of a customer may appear in this repository at all. The NoWayOS prime directive keeps client data out of every repository.

These rules apply already:

* **No secrets, keys or credentials** in a profile, not even development ones.
* **No personal data.**
* Examples and fixtures are synthetic and generic.
