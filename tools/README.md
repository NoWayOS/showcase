# tools: the make targets in detail

`make` lists every target; this page says what each does in full.

## Targets

| Command | Where | What |
| --- | --- | --- |
| `make` | host | list the targets |
| `make fmt` / `make lint` | container (`IN=host`: host) | format / `cargo fmt --check`, then clippy with `-D warnings` |
| `make test` | container (`IN=host`: host) | unit, integration, property and doc tests |
| `make doc` | container (`IN=host`: host) | API docs, warnings as errors |
| `make clean` | container (`IN=host`: host) | remove that environment's build output |
| `make nostd` | container (starts it) | build every crate except `HOST_ONLY_CRATES` (none today) for `aarch64-unknown-none` |
| `make deny` | container (starts it) | the NoWayOS baseline check (lints, profiles, deny settings, local-crate guard) of the root, `pds/` and `fuzz/` workspaces, then cargo-deny (licences, sources, advisories) for the root and `fuzz/` (`pds/`: `make pds-deny`). Only `fuzz/deny.toml` allows libFuzzer's licence; the other two ban `libfuzzer-sys` |
| `make sbom` | container (starts it) | a CycloneDX 1.5 SBOM per workspace (`showcase`, `showcase-pds`, with the standard-library crates, and `showcase-fuzz`, whose every component is `excluded`: nothing in it ships) in `build/sbom/`, by NoWayOS's `tools/sbom`: what the kiosk is built from is `required`; dev-dependencies, build-time tools and other platforms' dependencies are marked `excluded`, with the reason |
| `make secrets` | container (starts it, no network) | the tree, and every version of every file and every commit message on every ref, scanned for keys and credentials by NoWayOS's `tools/secrets-scan`: a finding names its file and line, never the text; reviewed false positives in `secrets-allow.toml`, one exact entry each with its reason; a shallow clone fails |
| `make qemu-test [SYSTEM=kiosk]` / `make qemu-test-all` | container (starts it) | build a system's PDs (`pds/`) and Microkit image with NoWayOS's make fragments, check its grants (`systems/NAME.grants`) against the description and the capDL, boot it in QEMU and check its output (`systems/NAME.expect`) |
| `make pi-show PI_DEVICE=DEV SYSTEM=showcase PI_TYPE=1` | host (image built in the container) | the showcase's launcher on the Pi 5's HDMI monitor (`SYSTEM=kiosk`: the reference kiosk alone), driven by what is typed in this terminal through the Debug Probe, or a USB keyboard on the Pi (NoWayOS's `tools/pi-run show --type`; Ctrl-] stops typing and leaves it running); `SYSTEM=kitchen-sink` tours the screens instead; `make pi-run PI_DEVICE=DEV PI_SYSTEMS=kiosk PI_WATCHDOG=15` types `systems/kiosk.qmp` instead and checks the log as far as the second session's end, 50 lines (a board run lasts at most the watchdog's 15 s); `make pi-run PI_DEVICE=DEV PI_SYSTEMS=showcase-tour` runs the showcase as a test system that asks for 300 s, plays all of `systems/showcase.qmp` - the pay at the pump's two sessions included - and checks `systems/rpi5b_2gb/showcase-tour.expect` |
| `make pds-lint` / `make pds-deny` | container (starts it) | rustfmt and clippy for `pds/` / cargo-deny for `pds/`, then rust-sel4 only at the commit NoWayOS pins |
| `make kani` | container (starts it) | Kani's proofs in `kiosk/showcase-kiosk-contract/src/proofs.rs` - `decode_action` and `decode_report` never panic, overflow or read out of bounds for any input up to `MAX_RECORD_LEN` and one byte more; a `SetText` keeps its length and zeros - then the mutant in `tools/kani-mutations.json`, without `SetText`'s length check, whose proof must fail (NoWayOS's `tools/kani-mutation`). Logs in `build/kani/` |
| `make fuzz` | container (starts it) | the fuzz targets in `fuzz/fuzz_targets/`, by NoWayOS's `make fuzz` (`tools/make/system.mk`): `action_decode`, `report_decode` and `network_decode` feed any bytes, as they are or behind a valid header the fuzzer picks, to `decode_action`, `decode_report`, `decode_from_network` and `decode_to_network`; each fails on a panic, a kind refused wrongly, a record that decodes but does not re-encode to the same bytes, or one changed by the bytes after it or accepted cut short. Each runs `FUZZ_SECONDS` (10); `FUZZ_TARGETS=NAME` for one, `FUZZ_INPUT=FILE` one target on one input. Corpus and any crash in `build/fuzz/`. `fuzz/` is a workspace of its own with its own lock: libFuzzer is signed off for development and CI fuzzing only |
| `make unsafe-audit` / `make std-crates-check` | container (starts it) | no `unsafe` code in either workspace / the standard-library crates built into the PDs are NoWayOS's reviewed list |
| `make screens` / `make screens-bless` | container (starts it) | the kiosk reference screens and the showcase's (`showcase/showcase-app`, `showcase/showcase-visitor`, `showcase/showcase-pump`) through Screen Compiler, built from `../screen-compiler` (its commit printed): every screen converts, or is refused, exactly as checked in (`src/generated`, `gaps.txt`), by `tools/screens` / rewrite them after a deliberate change, then review the diff. Our own synthetic screens only: never run Screen Compiler on untrusted `.tsx` |
| `make quiet-check` | host or container (Python standard library) | every system in `systems/` prints nothing derived from what people type (`tools/check-quiet`): it runs only Showcase's own programs (`showcase-*.elf`; a product built on the Showcase passes `--programs` with its own prefix), Showcase's display program runs the display PD quiet (`init_quiet`), every expect file forbids a frame's or scan-out hash (`!display-stub: frame`), and every run of text a script types (its serial steps decoded as `tools/qemu-test` sends them and read as NoWayOS's terminal decoder reads them, the keys taken out: control bytes, spaces, CSI and SS3 sequences; an ESC before any other printable byte is refused) starts with a text every expect file of that system forbids - the names start `zqvj`, the reference is `9081726354`; its own tests first (`tools/test_check_quiet.py`), one per rule |
| `make ci` | container (starts it) | checks `../nowayos` is at the commit `nowayos.rev` records with no local changes (else fails, naming both; refuses `NOWAYOS_EXPERIMENT`) and reports it, then secrets, lint, test, doc, nostd, deny, sbom and screens (when `../screen-compiler` is there; else a notice) with `--locked`, then fuzz, kani, quiet-check, pds-lint, pds-deny, pds-test, pds-miri, unsafe-audit, qemu-test-all and std-crates-check (image from `make container` in `../nowayos`) |

With `IN=host`, add `CARGO="cargo +stable"` (and never plain `cargo` in this repo: rustup would install the pinned toolchain). In a container shell, `make nostd-local`, `make deny-local` and `make ci-local` run the same checks without starting another container; on a host with the target, cargo-deny and Python 3.11 they run there too, with `IN=host` for `ci-local` (whose lint, test and doc otherwise start the container).
